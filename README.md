## Projeto em destaque

### Oficina de Roteiros

Uma aplicação web para criar, revisar e organizar roteiros em português, com:

- geração de roteiros curtos e longos;
- revisão baseada na pesquisa original;
- storyboard para planejamento visual;
- teleprompter com controle de velocidade e tamanho;
- biblioteca local para salvar roteiros.

**Tecnologias:** HTML, CSS e JavaScript.
